# Kaina - Resource Manager

![Flask](https://img.shields.io/badge/Flask-0D6EFD?style=for-the-badge&logo=flask&logoColor=white) ![SQLAlchemy](https://img.shields.io/badge/SQLAlchemy-333?style=for-the-badge) ![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white)

Kaina is a comprehensive, feature-rich web application for managing bookable facilities. It demonstrates modern Flask practices with a professional, AWS-inspired user interface.

## ✨ Features

-   **Search, Sort, & Filter**: The main dashboard provides powerful controls to quickly find the resources you need.
-   **Modern UI**: A professional and responsive light-blue theme inspired by the AWS console.
-   **Multi-Model Database**: Manages Users, Resources, Bookings, and Maintenance with SQLAlchemy 2.0.
-   **Booking Approval Workflow**: All new bookings must be approved by an administrator.
-   **Conflict Detection**: Prevents double-booking and conflicts with scheduled maintenance.
-   **Admin Panel**: A dedicated section for administrators to manage the system.
-   **Usage Reporting**: Calculates and displays the total hours each resource has been booked.
